# STYLY Shader Collection - Universal Render Pipeline version
## 360ImageToPortal
* 360 Image to Portal Shader
  * Converts a 360° equiangular cubemap image into a portal-like visual effect.

## Stereo
* Stereo Chroma Key Shader
  * Supports Side-by-Side (SBS) and Over-Under (OU) stereo image formats.
	* Includes the following features:
	  * Display Adjustment

### Fine-tune the appearance of stereo images.
* Horizontal and Vertical Fade

### Gradually fade the stereo image along horizontal or vertical axes.
* Chroma Key
  * Key Color: Specify the color to be keyed out.
  * Hue Range: Adjust the range of hues to key.
  * Fuzziness: Control the softness of the keying effect.
